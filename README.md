# Playwright E2E Automation Framework

세부 학습 과정 : https://www.notion.so/Playwright-E2E-1cdec11c55bb806aa260d36443a23057?source=copy_link

## Project Goal
Manual QA 경험을 기반으로, 유지보수성과 확장성을 고려한 Playwright 기반 E2E 자동화 테스트 프레임워크를 구축.

## Tech Stack
- Playwright
- TypeScript
- GitHub Actions
- Node.js

## Test Target
- SauceDemo

## Test Scope
- Login
- Product List
- Cart
- Checkout
- Error Validation
